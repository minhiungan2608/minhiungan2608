## Engineering focus

- **AI / ML:** representation learning through sensor quantization and a custom Transformer classifier.
- **Software:** an application workflow around a reusable Python modeling class, with input preparation, prediction, and save/load operations.
- **Data:** CSV inspection, preprocessing, external API ingestion, and interpretable model comparisons.

Project READMEs explain execution steps, verified behavior, and methodology limits. BIF currently performs tabular regression; the weather notebook analyzes forecasts from an external API. BERT's recorded evaluation uses overlapping windows and should not be read as evidence of independent-machine generalization.
